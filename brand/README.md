# Brand assets

Source artwork for MisterZine Plex: the wordmark's SVG sources
(`tools/prep_wordmark.py` derives the knockout and layered files from the source
trace) and PNG exports, retained for reproducibility. Nothing here is loaded at
run time; the app's header mark is `app/internal/ui/assets/misterzine-stacked-v1.png`,
the same image as `exports/misterzine-stacked-v1.png`. The renderer corrects
aspect ratio for CRT pixels.

These assets are original application material covered by the
[application terms](../release/TERMS.md); third-party names retain their ownership.
